## ARCHITECTURE

The repository is built with a highly modular, scalable, and data-driven approach:

```text
src/
├── components/       # Reusable UI architecture
│   ├── Navbar/       # Navigation system with scroll progress tracking
│   ├── SplineScene/  # 3D interactive graphics wrapper
│   ├── Icon.tsx      # Centralized icon system
│   └── ...
├── data/             
│   └── portfolio.ts  # The single source of truth for all content
├── styles/           
│   ├── global.css    # Layouts, responsive design, and section styles
│   └── tokens.css    # Design system variables (colors, fonts, spacing)
├── hooks/            
│   └── ...           # Custom React hooks (e.g., active section observer)
├── types/            
│   └── portfolio.ts  # Strict TypeScript interfaces for the data models
└── App.tsx           # Main application assembly and page sections
```

### Data-Driven Content Management
Instead of hardcoding text into the React components, the entire portfolio content is decoupled and stored in `src/data/portfolio.ts`. Updating a project, adding a new skill, or logging a new experience timeline node is as simple as updating an array in the data file. The UI automatically maps and renders the updated state.

## RUN LOCALLY

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
